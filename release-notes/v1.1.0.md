# Release Notes — v1.1.0

## Release Utilisateur

- **Sponsors sur le terrain** — Affichez les logos de vos sponsors directement sur le terrain en live, dans l'onglet terrain du match et dans l'export PDF
- **Détail des fautes par type** — La fiche joueur et le PDF affichent maintenant le détail par type de faute (personnelle, antisportive, technique, disqualifiante) en plus du total
- **Suppression définitive d'un match** — Possibilité de supprimer un match de l'historique de façon irréversible
- **Popup "Nouveautés"** — Un résumé des nouveautés s'affiche automatiquement après une mise à jour de l'application
- **Correction alignement stats** — Le tableau de statistiques est maintenant correctement centré
- **Correction publicité iOS** — Fix de l'identifiant publicitaire sur iOS
