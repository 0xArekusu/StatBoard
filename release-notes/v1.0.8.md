# Release Notes — v1.0.8

## Release Utilisateur

**Timeline, Radar & Tutoriel**

**Timeline de match**
- Nouvelle vue chronologique de vos actions en cours de match
- Indicateurs de fautes et de temps-morts dans la timeline
- Chargement avec indicateur de progression

**Page statistiques joueur**
- Nouveau graphique radar pour visualiser les points forts d'un joueur
- Page dédiée accessible depuis le résumé

**Statistique +/− (Plus/Minus)**
- Calcul automatique du différentiel de score quand un joueur est sur le terrain
- Affichable dans le résumé, filtrable dans le modal, exporté dans le PDF

**Tutoriel intégré**
- Un tutoriel interactif s'affiche au lancement de votre premier match pour vous guider

**Effectif & Équipes**
- Possibilité de sauvegarder l'équipe adverse pour la réutiliser
- Amélioration de la vue effectif avec chargement de la composition
- Jusqu'à 20 joueurs par équipe (était 15)
- Indicateur visuel pour les joueurs sans numéro de licence
- Amélioration des vues de roster

**PDF**
- Export des statistiques moyennes en plus des totaux

**Application**
- Alerte de mise à jour obligatoire si une nouvelle version est disponible
- Suppression de compte finalisée (backend)

**Corrections**
- Correction du score adversaire en mode extérieur
- Correction des couleurs en mode clair
- Correction du bouton fautes dans l'en-tête (mobile)
- Correction de l'avatar joueur
- Correction du chargement de composition dans la vue effectif
