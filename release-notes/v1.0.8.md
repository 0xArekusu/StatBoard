# Release Notes — v1.0.8

## Release Utilisateur

- **Tutoriel en début de match** — Un guide s'affiche au lancement d'un nouveau match pour vous prendre en main rapidement
- **Timeline de match** — Visualisez le déroulé de vos actions dans le temps avec des indicateurs de fautes et de temps-morts
- **Radar de statistiques joueur** — Une nouvelle page joueur avec un graphique radar pour visualiser ses points forts
- **Statistique +/−** — L'évaluation plus/moins est maintenant calculée, affichée, filtrée dans le résumé et exportée en PDF
- **Équipe adverse sauvegardée** — Possibilité de sauvegarder l'équipe adverse pour la réutiliser
- **Statistiques moyennes en PDF** — L'export PDF inclut maintenant les stats moyennes en plus des totaux
- **Mise à jour obligatoire** — Une alerte s'affiche si l'application doit être mise à jour
- **Limite effectif augmentée** — Jusqu'à 20 joueurs par équipe (au lieu de 15)
- **Indicateur de numéro de licence** — Un marqueur visuel sur les joueurs sans numéro de licence
- **Correction score extérieur** — Le score adversaire s'affiche correctement en match à l'extérieur
- **Correction couleurs mode clair** — Les couleurs s'affichent correctement en mode clair
- **Correction bouton fautes** — Le bouton fautes dans l'en-tête fonctionne correctement sur mobile
- **Correction avatar joueur** — Les photos de joueurs s'affichent correctement
