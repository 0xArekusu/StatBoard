# Release Notes — v1.0.7

## Release Utilisateur

**Actions enchaînées & Statistiques avancées**

**Actions enchaînées**
Après chaque action importante, l'app vous propose automatiquement d'enregistrer l'action suivante logique :
- Tir réussi → Passe décisive (assist)
- Tir raté → Rebond
- Contre → Action de contre
- Perte de balle ↔ Interception
- Faute provoquée → Faute reçue
- Faute commise → Enchaînement de fautes

**Statistiques équipe**
- Rebonds collectifs (rebonds d'équipe, séparés des rebonds individuels)
- Points des remplaçants dans le résumé
- Score filtrable par période dans le modal de résumé

**Export PDF amélioré**
- Noms des équipes remplacent "Nous / Eux" partout (PDF, historique, résumé)
- Gestion des matchs avec handicap dans l'export

**Compte**
- Bouton de suppression de compte disponible dans les paramètres

**Corrections**
- Correction du score adversaire en mode extérieur
- Correction des noms des joueurs adverses
- Correction de l'affichage des stats dans l'onglet carte joueur
- Correction de la couleur de faute
- Correction des labels dans l'historique
- Correction de l'ID AdMob iOS
