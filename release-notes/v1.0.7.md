# Release Notes — v1.0.7

## Release Utilisateur

- **Actions enchaînées** — Après chaque action, l'app vous propose automatiquement la suivante : tir réussi → assist, tir raté → rebond, perte de balle ↔ interception, faute provoquée → faute reçue, contre → action de contre
- **Rebonds collectifs** — Les rebonds d'équipe sont maintenant comptabilisés séparément des rebonds individuels
- **Points des remplaçants** — Visible dans le résumé de match
- **Score par période** — Filtrez le score par quart-temps ou mi-temps dans le modal de résumé
- **Noms d'équipe** — "Nous / Eux" est remplacé par les vrais noms d'équipe partout (résumé, historique, PDF)
- **Match avec handicap** — L'export PDF et l'écran résumé gèrent maintenant les matchs avec handicap de points
- **Suppression de compte** — Bouton disponible dans les paramètres
- **Correction score extérieur** — Le score adversaire s'affiche correctement en match à l'extérieur
- **Correction noms joueurs adverses** — Les noms des joueurs adverses s'affichent correctement
- **Correction couleur faute** — La couleur de l'indicateur de faute est corrigée
- **Correction historique** — Les labels dans l'historique des matchs sont normalisés
